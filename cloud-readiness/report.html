OKX Q2V 클라우드 이전 점검 — 2026-11-12 KST

판정: 실거래 클라우드 이전 준비 미완료. 실제 서버·계정 연결 없이 모든 우려 해소를 선언할 수 없다. 19개 오프라인 테스트 통과. 실행 프로그램·거래 규칙·주문·계정 설정 변경 없음.

Linux 2GB 추천은 서버용 실행기와 업데이트 구조 수정 및 실제 부하 검증을 전제로 한 후보이다. 현재 코드 그대로의 Linux 이전 추천은 철회한다. Windows도 무인 재시작 검증 전 완성 대안은 아니다.

항목상태근거 및 해소 조건
복구 후 재개모의검사 통과연결·미체결·체결불명·계정/설정 변경·사용자 중지 시 재개 차단. 실제 계정 복구는 별도 검사.
쓰기 요청 타임아웃모의검사 통과주문 결과 불명 시 UnknownOutcome. 자동 재전송하지 않고 대조 필요.
상태 파일모의검사 통과원자 교체 실패 시 이전 파일 유지, 손상 파일 시작 차단. 서버 장애 후 디스크 복원은 미검증.
업데이트 설치 전 검사모의검사 통과보유·일반주문·조건주문·진입 처리 중 차단. 통신실패도 설치 허용으로 처리하지 않음.
완료봉과 요청 제한모의검사 통과완료봉만 사용, 갭 검출, 공유 요청량/대기 검사. 실거래소 24시간 부하 검증 아님.
집 PC와 서버 동시 실행미해결 / 이전 차단현재 127.0.0.1 포트 잠금은 한 호스트 안에서만 유효. 이전 시 PC 신규진입 중지→미체결·보유 대조→PC 종료→상태 백업→서버 복원→서버 전용 키/IP 적용. 집 PC 기존 키 권한 회수 또는 서버만 허용하는 IP 설정은 실제 이전 마지막에 시행. 보유 중 기존 키를 먼저 폐기하면 보호 관리가 끊김.
Linux 무화면 실행미해결 / 이전 차단okx_bot.main이 Tk 생성, mobile.capture가 Dashboard 상태를 사용. 별도 headless 실행기·상태 모델 필요. 현재 Linux ZIP 즉시 이전 불가.
재부팅·자동 재시작미해결 / 이전 차단현재 프로그램은 OS 서비스 미구성. 프로세스 생존만으로 엔진/보호 스레드 정상 판단 불가. 엔진·위험감시 heartbeat와 복구 대조 후 재개 검사 필요. 사용자 중지는 재부팅 후에도 유지해야 함.
Linux 자동 업데이트미해결 / 이전 차단업데이터가 okx_bot.py를 자식 프로세스로 실행. systemd 관리에서 설치 작업과 재시작 책임 분리 필요. KillMode=none/process로 회피하지 않음. 실패·롤백·재부팅 중복 실행 시험 필요.
고정 공인 IP대상 서버 필요Lightsail dual-stack 및 Static IP 연결. 재시작 전후 동일 IP, 실제 OKX 출구 IP와 allowlist 일치 확인. Tailscale 100.x 주소를 OKX 허용 IP로 등록하지 않음. Exit node 사용 시 출구 변경 확인.
모바일 접속코드 확인 / 대상 서버 미검증127.0.0.1:8766, HTTPS Origin 및 로그인 검사 존재. 클라우드에 8766 공개 개방 금지. Tailscale Serve로 HTTPS 연결. 서버 이동 시 기존 PC의 ts.net 주소가 자동으로 따라오는 것은 아니므로 접속 주소 이전/갱신 검사 필요.
Tailscale 지속 연결대상 서버 필요서버 노드 키 만료 관리, Windows unattended 모드. 재부팅·로그아웃 후 접근 검증. 기본 전체허용 대신 필요한 기기와 포트만 허용하도록 ACL 확인.
2GB 메모리·CPU미검증2GB 충분하다고 판정하지 않음. 실제 전 종목 탐색+차트+모바일+업데이트를 최소24시간 측정. Lightsail CPU 버스트 고갈, OOM, 지연, swap thrash 검사.
네트워크·지연작업환경 표본만 측정공개 GET만 사용. 이 환경 결과를 서울/도쿄/싱가포르 VPS 성능으로 해석 금지. 대상서버 REST·WS 연결과 재연결, 429·403, private GET 별도 확인.
보호 SL·중단 대응실제 계정 확인 필요서버 종료 중에도 OKX에 남는 보호 주문의 실제 상태·수량 확인. 로컬 추적SL 계산은 서버 중단 시 갱신 불가. 체결가 및 무손실 보장 불가.
백업·보안·비용대상 서버 필요실행 중 상태 파일 무작위 복사 금지. 대조된 상태와 설정의 암호화 백업/복원, API 출금권한 없음, secrets 공개 저장 금지, 예산 알림, 스냅샷·미연결IP·세금 포함 총액 확인.
