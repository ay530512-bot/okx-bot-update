# KST 하루 +5~10% 복리와 꼬리 진입·추적손절

2026년 11월 22일에 고정한 연구다. 150 USDT 공유 계좌의 전일 마감 순자산을 매일 그대로 이월했다. 하루 전체 수수료·슬리피지·펀딩과 보유분 청산 비용을 반영한 마감 수익률이 +5% 이상 +10% 이하이면 그 하루를 목표 달성으로 센다. 무거래일도 포함한다.

## 검증 결과

최근 60일은 9월 23일~11월 21일 KST다. 31종목에 적용한 두 규칙의 공유 계좌는 35건을 체결해 150에서 153.0788 USDT가 됐다. 목표 범위에 든 날은 0일, 최고 일수익률은 +1.7053%, 최대낙폭은 3.1084%였다. 일별 마감 잔액이 같았던 날은 38일이었다. 가장 많이 번 종목 INJ의 기여를 빼면 공유 순손익은 −0.0501 USDT였다. 단일 최대 이익 거래만 빼면 +0.7510 USDT였다. 순청산가치가 당일 +7.5%에 이르면 전량을 청산하고 당일 신규 진입을 멈추는 방식도 시험했다. 이 공유 계좌에서는 발동이 0회였다.

진입·시간·손절 후보를 고른 30일은 9월 22일~10월 21일이다. 뒤 31일은 규칙과 시간을 고정해 다시 계산했다. 최근 60일 연속 계좌에서는 10월 21일에 156.4168 USDT였고 11월 21일에 153.0788 USDT였다. 뒤 31일만 새 150 USDT 계좌로 시작하면 13건에 146.7790 USDT였다. 같은 13건의 진입·수량·보유시간을 고정하고 추적만 기존 +1R 시작·1R 간격에서 바꿨을 때, 전체 순손익 차이는 +0.0447 USDT였다. 1R은 해당 포지션의 체결가와 최초 손절가 사이 거리다.

반전 롱·숏, EMA20 눌림 롱·숏과 스캘핑 롱에 3개 구조 손절 폭, 6개 청산 방식, 5개 진입 필터, 12개 KST 진입 구간, 두 일별 횟수 상한 및 두 수량 방식을 적용했다. 24,090개의 시장 신호로 21,600가지 설정을 비교했다. 앞 30일의 마지막 180분 신호를 제외해 뒤 구간의 청산 가격이 선택에 쓰이는 것을 막았다. 양쪽 15일 순익과 최대 이익 거래 제외 순익이 양수이고 7일 이상에 걸쳐 12회 이상 체결한 설정에서 방향별 한 개를 골랐다. 두 후보가 이 기준을 통과했다. 포트폴리오 계좌는 종목 및 규칙 중복을 막고 최대 3자리, 3 USDT 유보, 3~5배, 예상 건별 위험 0.5%와 합산 2%를 지켰다. 두 후보는 한 자리의 3배 전액이 위험 한도를 넘으면 주문 계약 수를 줄이는 모의 방식을 사용했다.

가격·거래량·펀딩은 OKX 공개 자료를 사용했다. 양쪽 각각 수수료 0.05%, 슬리피지 기본 0.05% 또는 스트레스 0.10%를 가정했다. 실제 호가 대기열, 개인 계좌 체결 지연, 사용자 PC의 모의 관찰 장부는 공개 자료로 알 수 없다. 압축 파일의 coverage.json은 과거 원시 파일 CRC와 종목별 대조 범위를 담는다. 첫 60일의 31 × 86,400개 1분 구간에서 거래량과 거래가 있었던 분의 고저를 대조했다. 11월 21일은 공개 완료 1·5·15분봉으로 불가능한 구간을 제외하고 BREV의 숏 후보 2곳을 공개 체결로 확인했다. 양쪽 모두 진입 조건을 채우지 못했다. 마감 자료를 연구 전에 관찰했으므로 이번 시간 순 비교는 역사 검증이다. 고정 이후 처음부터 끝까지 새로 들어오는 날짜는 11월 23일 KST다.

## 재현

이 디렉터리의 research.zip을 풀고 기존 연구와 동일한 PC_STUDY, PC_RELEASE, PC_FLOW, PC_DAYSET 및 PC_WICK30_SOURCE 경로를 지정한다. PC_STUDY에는 PC 2.5.0 시간표 재현, target10, wick_touch, 해당 기간의 공개봉 및 tick_cache가 있고, PC_WICK30_SOURCE는 wick30_scalp20 패키지의 source 디렉터리다. PC_DAYSET에는 11월 21일 거래소 직접 완료봉과 공개체결 다운로드 코드가 있다. 당시 배포 패키지의 SHA-256은 index.json에 기록했다. Python, NumPy, pandas, C++17 컴파일러가 필요하다.

```sh
mkdir -p cache
python load_market.py
g++ -O3 -std=c++17 -shared -fPIC paths.cpp -o cache/paths.so
python events.py
python search.py
python account.py
python last_scan.py
python last_fill.py
python verify.py
python trail_check.py
python sizing_check.py
```

research.zip의 cache/training.csv.gz는 전체 설정, frozen.json은 선택한 값과 통과 여부, accounts.csv는 단독·공유·비용·계좌 수익 잠금 비교다. newest_daily.csv.gz 및 newest_shared_fills.csv.gz는 최근 일별·체결 장부, same_contracts.csv는 동일 수량의 추적 방식 차이와 신호 후 5·15·30분 움직임, position_constraints.csv는 실제 계약 수를 결정한 제약과 고정 수량 비용 스트레스다. 13건의 양쪽 추적 방식 26개 청산 시점이 별도 체결별 순차 재생과 일치했다. 지표와 매수가·매도가에 다음 봉의 종가는 사용하지 않았다. 이 연구의 배포 판정은 보류다.
