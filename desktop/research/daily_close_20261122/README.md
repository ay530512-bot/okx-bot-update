# OKX 계좌의 한국시간 일별 순수익 검증

2026년 11월 22일 KST부터 연구 목표는 각 한국시간 거래일의 마감 순자산이 그날 시작 순자산보다 10% 이상 증가하는 것이다. 150 USDT에서 출발하는 첫날 기준은 165 USDT다. 다음 날은 직전 마감 순자산을 기준으로 계산한다. 60일은 관찰 기간이다.

일별 장부는 계좌를 연속 운용하고, 수수료·슬리피지·펀딩과 자정을 넘긴 보유분의 예상 청산 비용을 포함한다. 포지션과 체결이 모두 없는 날도 포함한다. 거래소 공개 체결가를 사용한 모의 순청산가치로 계산하며 각 자정에 매매 주문을 내지 않는다. 비용 가정, 독립 검증, 종목별 계약 크기 및 기존 포지션 보호 조건은 policy.json과 이전 재현 패키지에 기록했다.

기존 두 꼬리 반전과 긴 꼬리 스캘핑에 밴드까지의 여유 폭, 직전 완료봉 내 종가 위치, 변동폭과 거래량 조건을 조합했다. 시그널 시각과 전량 추적손절을 고정했다. 9월 23일~11월 21일은 개발 자료이고, 고정된 가설의 첫 온전한 새 관찰일은 11월 23일이다. 20~24시 스캘핑 및 이를 포함한 묶음은 기존 기회 자료의 마지막 날 마감 직전 보유시간 제한을 별도 표시했다.

study.py는 9c7f65ddca0ba633557a7515e2aee606c5ff231f의 desktop/research/wick30_scalp20_20261122/research.zip에 담긴 원시 재현 환경과 캐시를 사용한다. 기존 연구의 환경변수를 설정하고 PC_WICK30_SOURCE에 이전 연구 source 폴더를 지정해 실행한다. research_log.csv는 조건별 누적 연구 장부이고 daily.csv.gz는 일별 마감과 비용 스트레스 원장이다.
