# PC 2.6.0 진입 금액과 초기 손절

신규 주문은 USDT 기준 계좌 자산에서 3 USDT를 한 번 남기고 나머지를 세 자리로 나눈다. 각 자리 예산에서 시장가 진입 수수료를 확보하고 계약 단위 아래로 내림한다. 자동 배율의 상한은 상대 거래량, EMA20 기울기와 이격, RSI 변화와 봉 마감 위치로 정한다. 첫 꼬리 재시험의 손절은 첫 극값 바깥에 ATR 0.15배 또는 두 호가 중 큰 값을 더해 설정한다. 3배까지 낮춰도 한 자리의 추정 손절 위험이 배정 기준 시드의 0.5%를 넘으면 신규 주문을 건너뛴다. 합산 추정 위험 한도는 2%다.

피라미딩 없이 한 규칙당 한 포지션을 사용한다. 동일 종목 중복을 막으며 수동 보유와 신규 미체결 주문도 세 자리에 포함한다. 하나의 탐색 주기에 여러 규칙이 진입 자격을 얻으면 주문마다 거래소 배율·잔고·손절과 남은 자리를 다시 확인한다. 수동 시장가 버튼은 5배다.

## 재현

PC 배포 ZIP을 풀어 둔 상위 폴더에서 `python test_pc260.py -v`를 실행한다. 가짜 거래소로 150 USDT에서 3배 롱, 4배 숏, 5배 롱 주문을 한 주기에 시험하며 각 방향의 주문에 첨부한 손절 가격도 검사한다.

`market_check.py`와 `account_check.py`는 2026년 9월 22일부터 11월 20일까지 한국시간 기준 31종목의 시간표를 재현한다. 배포본 경로는 `PC_PACKAGE`, 직전 연구의 검증된 recent 시세 폴더는 `PC_REPLAY_INPUT`, 종목 명세 JSON은 `PC_INSTRUMENTS`로 지정한다. 최근 입력은 저장소의 target10 연구 inputs.py가 생성하는 심볼별 1분·15분 배열이다.

```
python market_check.py --workers 5
python account_check.py ins.json
```

`market_result.json`에 계좌 결과가 있다. 150 USDT, 수수료와 슬리피지 각각 편도 0.05%, 공개 펀딩 정산을 반영했다. 1분 체결가격 봉과 다음 시가를 사용하므로 시점별 호가 깊이, 실시간 마크가격 손절 체결과 실제 개인 PC의 모의관찰 장부는 재현하지 않는다. 기록을 비우고 시작한 경우와 같은 후보에서 실거래 자격 요건만 생략한 비교를 담았다. 두 번째 꼬리에서 반등하는 첫 체결을 이용하는 별도 연구는 wick_touch_20261121에 있다.

## 첫 꼬리와 이평선 반응에서 즉시 진입한 별도 비교

`wick_recheck.py`는 wick_touch_20261121의 고정된 네 규칙을 같은 31개 종목의 공개 체결 순서로 다시 재생한다. 첫 꼬리 재시험의 여유 폭을 ATR 0.15배와 두 호가 중 큰 값으로 바꾸고 3~5배, 3 USDT 유보, 세 자리 배분과 건당 0.5% 추정 손실 한도를 적용한다. 이평선 눌림·반등 규칙은 해당 두 번째 꼬리의 극값 바깥 ATR 0.25배 또는 두 호가를 사용한다. 배율 자료는 신호 직전 마감한 5분봉까지만 읽는다. 이전 연구의 관측 시간과 데이터는 그대로 사용하므로 같은 과거 구간에서 변경 효과를 비교하는 연구다. 손절 발동과 체결은 공개 체결가로 근사했다. 연구 폴더에 이전 tick_replay.py의 recent 전체 체결 캐시를 준비하고 다음을 실행한다.

```
python /path/to/wick_recheck.py
```

실행 전에 PC_PACKAGE에 배포 패키지 폴더를, PC_WICK_RESEARCH에 기존 wick_touch 연구 코드 폴더를 지정한다. 기본 비용 및 슬리피지 두 배 비교 결과는 wick_risk_result.json에 있다.
