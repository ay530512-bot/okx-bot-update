# OKX 폰 1.3.0 — 기존 3자리 + 추세 전용 1자리

사용자 승인에 따라 기존 1.2.9를 확장한 설치 업데이트입니다. 연구 ZIP을 기존 폴더에 덮어쓰는 방식이 아닙니다.

## 자리와 자금

| 구분 | 기존 규칙 | 새 추세 규칙 |
|---|---|---|
| 자리 | 기존 눌림목·확정반전·두꼬리 세 규칙이 최대3자리 공유 | 최대1자리 예약 |
| 진입 | 기존 mild726 OR two_wick732 유지. 서로 반대 방향 신호 충돌 시 대기 | 아래 조건 모두 확인 후 롱 |
| 배율 | 일반 코인10배, BTC20배, ETH/SOL15배 유지 | 해당 경로만5배 |
| 목표 증거금 | 기존 계좌배분 기준의 3USDT 유보 후1/4 | 동일하게1/4 |
| 청산 | 최초2ATR SL, 관측+20%ROE 절반1회, Q2X 잔량보호, 최대6시간 | 최초2ATR SL, 절반익절 없음, 전량추적, 최대72시간 |

추세 조건이 없으면 예약 자리는 비워 둡니다. 기존 세 규칙에 각각 한 자리씩 주는 방식은 아닙니다. 보유·미체결·수동 포지션을 자리 검사에 포함하며 전체 최대4개를 유지합니다. 업그레이드 당시 기존 포지션4개가 있더라도 강제로 청산하지 않습니다. 새 진입부터3+1 배분을 적용합니다. 같은 종목 중복 진입은 막습니다.

표시 증거금은 실제 잔고·수동 보유분·계약단위에 영향을 받습니다. 거래소 최소수량·수수료·가용자금 검사를 통과해야 하며, 부족하다고 임의의 소액 대체 주문을 넣지 않습니다.

## 추세1자리의 정확한 진입

1. 한국시간15:00 이상, 다음날09:00 미만에만 신규 진입합니다. 보유분을09시에 강제청산하지 않습니다.
2. 매시간 확정1시간봉 종가를 당일KST09시 시가와 비교하여 양의 상승률1위만 대상으로 합니다. 현재24시간 상승률이나 하루가 끝난 뒤의 최종1위를 쓰지 않습니다. 주식연동·지수/스테이블 연동 및 BTC/ETH/SOL은 이 알트코인 경로에서 제외합니다.
3. 확정1시간봉 종가가SMA50 위이고 SMA50이3봉 전보다 높아야 합니다.
4. 확정15분봉 종가가 직전20개15분봉 고가를 돌파하는 새로운 신호가 발생하면 대기합니다. 반복해서 같은 신호를 재등록하지 않습니다.
5. 돌파 신호 종가에서 그때의15분ATR의0.5배 아래를 눌림 기준으로 고정합니다. 이후 다른 확정15분봉의 **종가**가 그 기준 이하가 되면 진입 후보가 됩니다. 저가만 닿아서는 진입하지 않습니다. 추가 반등 확인봉은 요구하지 않는 `dip_only` 방식입니다.
6. 진입 때도 상승1위·1시간 추세를 유지해야 합니다. 순위/시간/추세가 무효가 되거나 관측이 건너뛰면 대기를 폐기합니다. 새 데이터가 없는 동안 오래된 신호를 재활용하지 않습니다.
7. 후보는 확인봉 마감 후90초 안에 최신 호가·시세·계좌·손절·수량 검사를 모두 통과해야 시장가로 제출합니다. 따라서 과거검사의 다음 봉 시가와 실제 체결가는 같다고 보장하지 않습니다.

순위는 전체 대상 종목의 같은 시각 자료가 모인 뒤 계산합니다. 일부만 수신한 상태에서 그 안의1위를 전체1위로 취급하지 않습니다. 자료가 부족하면 추세 진입을 보류하고 기존 경로는 계속 검사합니다.

## 추세 손절과 추적

- 최초SL: 눌림 확인봉 종가 − 2×15분ATR. ATR은 확인봉 이전의 확정봉 기준이며 기존 주문단위 반올림 검사를 유지합니다.
- 이후SL: 기존SL과 `진입 후 실제 관측 최고가격 − 2×확정1시간ATR` 중 높은 값으로만 이동합니다. 손절선을 아래로 넓히지 않습니다.
- +20%ROE 절반익절, 기존6시간 종료, 기존 Q2X 반전 청산은 추세 포지션에 적용하지 않습니다. 기존 포지션에는 그대로 적용합니다.
- 거래소 마크가격 기준 보호SL을 동반하고 기존 주문/손절 확인 절차를 사용합니다. 재시작 시 저장된 경로·최고 관측가격·보호선을 이어받습니다. 중단 중의 가상의 최고가를 봉 고가로 복원하지 않습니다.
- 실제 수신 지연·급변·체결 미끄러짐 때문에 손절선과 체결가가 다를 수 있습니다.

## 설치

기존 화면에서 **활동·설정 → 폰 새 버전 확인 → 업데이트**로1.3.0을 설치합니다. 1.2.6~1.2.9에서 직접 업데이트를 지원합니다.

수동 대체 설치는 실행 기기의Termux에서 받은 `phone_1_3_0_setup.py`를 실행합니다. 기본 경로가 `~/okx-phone`인 경우:

```sh
python -B ~/downloads/phone_1_3_0_setup.py
```

파일 저장 경로가 다르면 해당 실제 경로를 사용하세요. 설치기는 이전 파일 해시를 검사하고 보유분·거래소 보호주문을 대조해 인계합니다. 처리 중인 주문이나 보호 불일치가 있으면 설치를 보류합니다. 기존 계산모드(원래 방식/4개 분산)는 유지됩니다.

새 실행기의 준비 확인 전에는 새 추세 진입을 잠시 막습니다. 준비 실패 시 기존 인계/복원 절차를 사용합니다. 사용자가 신규 진입을 중지했던 상태는 자동으로 해제하지 않습니다.

## 검증 범위

`test_release.py`는 네 이전 버전의 버튼 업데이트·자동시작 등록, 변조 거절, 설치 재실행, 자리 제한, 시간/순위, 원래 시장가 주문·5배·1/4 목표증거금·동반SL, 재시작 후 경로 보존, +20% 절반익절 배제, 추적선 비확대,72시간 종료, 구독 반복추가/삭제 방지, 기존 계산모듈 무변경을 확인합니다. `test_audit.json`에 실행 결과를 기록합니다.

앞서 사용한 Binance2024년2~3월 실제 봉 자료에서 `dip_only`의110개 신호에 대해 시점·기준가·ATR·초기SL·대기시점·눌림기준이 이전 연구와 같은지 비교했습니다. 이는 **재사용 자료에 대한 구현 일치 검사**입니다.

실기기의 장시간 연결·실제 주문 체결은 이번에 원격 시험하지 않았습니다. **기존3자리+추세1자리로 제한한 전체 공유계좌 수익성은 별도 검증되지 않았습니다.** 이전 추세 단독 과거 수익률을 이 배분의 기대수익으로 간주하지 않습니다.

재현에는 기존의Q2X 원본과 호스트24~27 fixture 및 `top3_trend_5x`, `top1_15kst`, `top1_15_entry3` 연구 자료가 필요합니다. 이번 설치기는 기존 검증된 원본을 재사용하며 계정 비밀정보를 포함하지 않습니다.
