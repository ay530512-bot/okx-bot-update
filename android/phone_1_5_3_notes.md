## 확인한 원인과 수정

JCT-USDT-SWAP은 2026년 11월 16일 20:00 KST에 상장됐습니다. 그날 09:00 KST의 봉은 존재하지 않는데, 기존 코드는 이를 수집 누락으로 처리해 다른 종목의 추세 순위까지 대기시켰습니다. 사용자 진단의 JCT 1시간봉 3개·09시 기준봉 대기와 거래소 공개 `listTime=1794826800000` 및 [공식 상장 공지](https://www.okx.com/help/okx-to-list-perpetual-future-for-janction-crypto)가 일치합니다.

현재 순위 기준인 KST09 이후에 상장했다고 거래소 종목 정보로 확인되는 SWAP만 당일 순위 비교에서 제외합니다. 종목 식별자·종류·거래 상태·상장 시각이 유효해야 합니다. 해당 종목의 전체 시세 감시와 공용 규칙 검사는 유지하며, 다음 KST09 기준일에는 순위 대상에 다시 포함합니다. 09시 당시 존재하던 종목의 자료가 누락됐거나 상장 정보가 불명확하면 계속 순위를 차단합니다. 상장 가격을 09시 가격으로 대체하거나 일부 자료만으로 임의의 상승 1위를 정하지 않습니다.

화면과 진단파일에 당일 순위 제외 종목과 이유를 표시합니다. 1.5.2의 수신 CPU 개선·감시/실행 연결 분리를 포함합니다. 진입 패턴, 거래 시간, 90초 유효시간, 시세 유효성, 수량·레버리지·손절·보유 관리·설정은 동일합니다.

231개 Python 검사와 JavaScript 화면 검사를 통과했습니다. 신규상장 때문에 기존 코드가 순위를 차단하는 재현, 기존 종목의 실제 자료 누락 차단, 다음 기준일 복귀, 추세 롱·오전 숏의 주문 요청·모의 체결·손절 확인을 포함합니다. 1.5.1/1.5.2 업데이트 인계 경로와 설치 파일 해시도 검사했습니다.
