# 사용자 지정 버전 정책

현재 표시 버전: **1.1.2**. 누적 기능명 대신 숫자 하나만 표시합니다.

- 첫째 자리: 대형 업데이트. 예: 1.1.2 → 2.0.0
- 둘째 자리: 매매 규칙 변경. 예: 1.1.2 → 1.2.0
- 셋째 자리: 디자인 및 소규모 수정. 예: 1.1.2 → 1.1.3
- 앞자리를 올리면 뒤쪽 자리는 0으로 초기화합니다.
- 여러 종류가 섞이면 가장 큰 변경에 해당하는 자리만 올립니다.
- 변경 내용은 릴리스 설명에 기록하고 버전 이름 뒤에 계속 붙이지 않습니다.

호환성 관리용 내부 배포번호는 표시 버전과 별도입니다. 기존 모바일 업데이트 v1 및 화면 여백 v1에서 모두 1.1.2로 업데이트할 수 있습니다. 32px 여백은 포함하며 매매 규칙은 변경하지 않았습니다.
