# OKX Ai trade - 1.2.0

1.1.9(내부 배포 17)에서 폰 화면의 업데이트 버튼으로 설치하는 폰 전용 배포입니다.
새 버전의 내부 배포번호는 18입니다. 1.1.9의 공개 시세 연결 변경을 그대로 포함합니다.

- 자동 V7.32 진입으로 최종 선택된 조건이 추세 눌림목 롱일 때만 목표 증거금을 기존의 1/4로 적용합니다. 같은 방향에서 기존과 두꼬리가 동시에 성립하면 기존 선택 우선순위를 그대로 따릅니다.
- 두꼬리 단독, 눌림목 숏, 기타 경로, 수동 주문이 쓰는 증거금은 그대로입니다. 기존 OR 진입 조건, 레버리지, 손절가와 청산 규칙도 유지합니다.
- 계약 최소 수량에 못 미치거나 기존 체결 검사를 통과하지 못하면 진입은 보류됩니다. 기존 계좌 한도, 주문 직전 수량 대조 및 보호 주문 확인은 유지합니다.
- 기존 보유분을 강제 청산하거나 주문을 취소하지 않습니다. 보유·미체결·거래소 손절과 실행기 소유권을 대조한 후 인계하고, 원래 사용자 운용 요청은 그 상태대로 복구합니다. 안전하게 인계할 수 없으면 설치를 보류합니다.

Q2X 원본과 설정 파일은 덮어쓰지 않습니다. 새 폰 실행기에서 고정된 Q2X 파일의 해시를 다시 확인하고 해당 목표 증거금 계산만 메모리에서 적용합니다. 이전 폰 실행기로 복원하면 감액도 함께 해제됩니다.

`phone_pullback_size.py`는 설치기에 내장된 폰 주문량 정책의 검토용 원본입니다.
