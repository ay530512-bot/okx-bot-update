- 봇이 이미 수신한 확정봉을 재사용합니다. 추가 REST 조회, 웹소켓 구독, Telegram 발송은 없습니다.

- 클릭하면 해당 종목의 현재 15분 차트로 이동합니다. 기존 수동 롱/숏 5배 버튼에서 별도로 진입합니다. 카드 클릭은 주문을 보내지 않습니다.
- 현재 허용된 시세 목록에 없는 종목의 카드는 비활성화됩니다. 기존 계정·연결·주문·중복·보호 검사 그대로입니다.

**범위:** Telegram 대화/기존 알림 프로그램을 직접 동기화하지 않습니다. 접근 가능한 배포 코드에서 해당 별도 알림 생성기를 찾지 못해 메시지에 나타난 기준으로 수신봉에서 재구성합니다. Telegram의 종목 범위·수신 시각·중단 기간과 완전히 일치한다고 보장하지 않습니다. 수신하지 못한 종목/봉은 누락될 수 있어 최신 확정봉 확보 종목 수와 검사 시각을 표시합니다. 신규 실행 시 사용 가능한 최근 봉을 소급 표시할 수 있으며, 현재 새로 발생한 알림이라고 오인하지 않도록 봉 마감 시각을 사용합니다.

## 유지되는 규칙과 검증 한계

1.3.1 신호 선택·주문·수량·청산·손절·4개분산 코드 유지. 알림이 자동매매 OR 조건으로 추가되지 않습니다.
확정반전과 눌림목은 원래 1시간 추세 상태에 따라 선택되며, 두꼬리는 별도 OR입니다. 추세 전용 5배 한 자리도 그대로입니다.

재현 테스트는 이 폴더의 test_alerts.py, test_dom.cjs, test_release.py를 사용합니다. test_ui.cjs는 브라우저 환경에서 실행하는 별도 검사입니다. 이번 실행 환경의 Chromium은 socket 생성 제한으로 시작되지 않아 화면 렌더링/아이폰 실기기 검증을 완료하지 못했습니다. DOM 동작 검사는 별도로 실행했습니다. 실거래 주문을 테스트하거나 휴대폰을 원격 재시작하지 않았습니다.

검사용 순서: build_release.py → test_alerts.py → test_dom.cjs → test_release.py. 이전 host-v24~29와 고정 core121, 재사용 역사자료가 있어야 전체 회귀가 실행됩니다. 2024-02~03 Binance 과거110신호 회귀는 기존 추세 결과 보존 확인이며 신규 수익성 검증이 아닙니다.
