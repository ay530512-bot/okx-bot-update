# OKX Ai trade 1.5.1

휴대폰 화면의 설명과 업데이트 버튼을 보기 쉽게 조정했습니다.

- 상단 설명을 **버전 제목 / 자리 배분 / 기존 롱 / 추가 숏**으로 나눴습니다.
- 제목은 14px, 설명 본문은 12px, 시간·보조 문구는 11px로 줄였습니다. 제목·항목은 연두색, 본문은 회색, 시간은 밝은색으로 구분합니다.
- ‘폰 새 버전 확인’ 및 ‘확인한 새 버전 설치’ 버튼에 **2px 연두색 테두리**를 적용했습니다. 터치 영역은 최소 48px을 유지하고, 처리 중 비활성 상태에서도 테두리는 보입니다.
- 새 화면 파일의 주소에 버전을 넣어 새로고침 시 이전 스타일이 남지 않게 했습니다.

**활동·설정 → 폰 새 버전 확인 → 1.5.1 설치** 후 새로고침합니다. 기존 1.5.0에서 바로 설치할 수 있는 누적 업데이트입니다.

이번 변경은 화면 표시와 배포 버전 정보에 한정됩니다. 1.5.0의 롱·오전 숏 조건, 전환 순서, 손절·추적, 주문 수량, 운용 시간과 보유·보호 인계 로직은 그대로입니다. 전략 파일과 인계 파일이 이전 버전과 동일한지 해시로 대조했으며, 설치 파일의 구버전 인식·준비·변조 거부를 확인했습니다. 실제 휴대폰 설치는 사용자가 업데이트 버튼으로 진행합니다.
