# 폰 급등·급락 텔레그램 알림 v1

기존 `~/okx-phone/phone_notifications.json`에 저장된 텔레그램으로 별도 시세 알림을 보냅니다. 기존 폰 실행기는 재시작하거나 수정하지 않습니다. 주문·계좌 API 또는 매매 모듈을 사용하지 않습니다.

## 고정 기본값

| 항목 | 동작 |
|---|---|
| 범위 | OKX 거래 중인 암호화폐 선형 USDT 무기한 전체, BTC/ETH/SOL 포함 |
| 제외 | 비암호화폐 분류, 주식 연동 그룹, 기존 strategy_config의 stock_linked_symbols |
| 감지 | 최근 약 5분 가격 변화 +3% 이상 또는 −3% 이하 |
| 가격 기준 | 공개 ticker의 last, 레버리지 ROE 아님 |
| 관측 간격 | 전체 ticker 묶음 15초마다 1회, 개별 코인 호출 없음 |
| 종목 목록 | 시작 시 및 1시간마다 공개 instruments 1회 |
| 중복 방지 | 동일 종목·방향 30분, 재시작 후에도 기록 유지 |
| 전송 빈도 | 최대 1분에 1개 묶음. 20종 초과 동시 감지는 변동률 상위 20종과 생략 수 표시 |
| 메시지 | 종목, 방향, 변동률, 기준/최근 가격, 실제 비교 시작·종료 KST |

알림 범위는 시세용 전체 암호화폐 목록입니다. 봇의 최종 진입 후보·거래량 순위·준비 신호 목록과 동일하다는 뜻은 아닙니다. 시세 급변만으로 진입이나 청산하지 않습니다. 알림 전용 기본값은 연구로 수익성이 검증된 매매 임계값이 아닙니다.

## 설치와 확인

검토한 커밋의 `android/phone_move_alerts.py`를 내려받아 `python 파일명 --install`로 실행합니다. Python 표준 라이브러리만 사용합니다. 기본 경로는 `~/okx-phone`이며 `--root`로 바꿀 수 있습니다.

설치는 `~/okx-phone/move-alerts-v1/`와 `~/.termux/boot/95-okx-move-alerts`만 생성/갱신합니다. 기존 거래 프로그램, 키, 설정, Tailscale 및 알림 수신자 파일은 변경하지 않습니다. 같은 버전 재설치는 중복 프로세스를 생성하지 않습니다. 설치 완료 표시는 Telegram 전달 성공의 증명이 아닙니다.

처음 공개 시세를 정상 수신하면 `[급등·급락 알림 연결]` 메시지 전송을 시도합니다. 이후 최소 5분 시세를 수집해야 급변 알림이 나옵니다. 기존 Termux:Boot를 설치한 뒤 한 번 열어 두어야 재부팅 자동 시작을 이용할 수 있습니다. 안드로이드에서 Termux를 종료하거나 절전으로 중단하면 알림도 중단됩니다. 실제 폰에서 장시간 실행 및 Telegram 수신은 별도 확인이 필요합니다.

상태 확인:

```sh
python ~/okx-phone/move-alerts-v1/phone_move_alerts.py --status
```

알림만 중지(매매 유지):

```sh
python ~/okx-phone/move-alerts-v1/phone_move_alerts.py --stop
```

재개는 같은 설치 파일의 `--install`을 사용합니다. 다른 버전으로 교체하기 전에는 `--stop` 후 `--status`의 `process_running: false`를 확인합니다.

## 정확성 및 장애 처리

- 15초 간격 관측이므로 비교 간격은 실제로 300~330초이며 메시지에 실제 시간을 표시합니다. 캔들 완성 기준이나 5분 동안의 최고/최저 범위가 아닙니다. 관측 사이에 발생했다가 되돌아온 급변은 놓칠 수 있습니다.
- 종목별 45초 초과 수신 공백이 있으면 그 종목의 가격 이력을 초기화합니다. 재접속 전후 가격을 이어 붙이지 않습니다. 오래되거나 역순인 시세도 사용하지 않습니다.
- 거래소 오류는 지수 대기(최대 15분) 후 재시도합니다. 공개 시세 조회가 추가되므로 기존 거래 연결 장애를 고치는 기능은 아닙니다.
- Telegram 429 응답은 retry_after를 지킵니다. 수신 여부를 알 수 없는 전송 오류는 중복 방지를 우선해 같은 이벤트를 재전송하지 않으므로 일부 알림은 누락될 수 있습니다. 알림 자체가 손실 방지나 체결을 보장하지 않습니다.
- 오래된 대기 알림(60초 초과)은 폐기합니다. 장애 복구 뒤 묵은 알림을 몰아서 보내지 않습니다.
- 토큰과 대화 ID는 기존 개인 설정에서만 읽으며 명령행·진단 출력·GitHub에 기록하지 않습니다. 설치/상태 파일에는 비밀 토큰이 들어가지 않습니다.

## 검증

`python -m unittest -v test_phone_move_alerts.py`

실제 네트워크/Telegram 전송 없이 시간 진행을 모의한 실행기 통합 검사를 포함합니다. 상하방 계산, 초기 수집, 시세 공백/역순/중복/오래됨, 30분 기록 유지, 다종목, 종목 필터, 메시지 길이, 공개 API 경로 제한, 429, 기존 파일 보존, 토큰 출력 방지를 검사합니다. 개발 환경 검사를 실제 폰 설치·실수신·장시간 가동 완료로 표현하지 않습니다.

검토 자료(2026-11-14 KST):

- OKX 공식 API: https://www.okx.com/docs-v5/en/#order-book-trading-market-data-get-tickers
- Telegram 공식 sendMessage/ResponseParameters: https://core.telegram.org/bots/api#sendmessage 및 https://core.telegram.org/bots/api#responseparameters
- 기존 폰 실행기 `notification_settings`와 시세 `market_rows` 구현. 거래 전략은 복제·교체하지 않음.
